Pattern Input

Subset parser for Tidal-style mini-notation

Ctrl/Cmd + Enter

track drums { seqP [ stack [ ... ], stack [ ... ] ] } creates a track from a time-ordered sequence of patterns.

[ ... ] subdivides time inside a step. *4 repeats inside the current span. ~ creates a rest.

Inside each seqP step, use s "bd cp hh", n "c4 e4 g4" # s "lead", or stack [ ... ]. Plain stack syntax still works and becomes a default single-step track.
